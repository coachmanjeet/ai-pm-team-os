# Tracker — Work Items & Decisions

Lightweight tracking for ideas, bugs, tasks, and decisions. Use `/tracker` skill to add entries.

| File | Tracks |
|------|--------|
| `ideas.md` | Product ideas backlog (ID, title, status, priority, source) |
| `bugs.md` | Known issues and defects (ID, severity, status, GUS ref) |
| `tasks.md` | Action items (ID, status, assignee, due date) |
| `decisions.md` | Strategic decisions with rationale and impact |
