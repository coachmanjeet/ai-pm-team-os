# Terminology Verification

## ALWAYS

**Verify terminology alignment** before incorporating any external input (documents, research, transcripts, references). Flag entity name mismatches or contradictions to the PM BEFORE proceeding with the task.

Reference `context/TERMINOLOGY.md` as the source of truth for platform terminology.

## NEVER

**Proceed with contradictory or mismatched terminology** without flagging it first. Stop and clarify with the PM when entity names, object names, or key terms in external inputs don't match the current working context.
