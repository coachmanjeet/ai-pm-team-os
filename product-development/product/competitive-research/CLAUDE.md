# Competitive Research

Competitive intelligence for Agentforce. Each competitor gets its own folder.

## Key Files

| File | What's Inside |
|------|--------------|
| `competitive-matrix.md` | Feature comparison matrix across all competitors |
| `competitors/[name]/CLAUDE.md` | Per-competitor overview (positioning, strengths, weaknesses) |
| `competitors/[name]/tldr.md` | Quick summary for reference |
| `competitors/[name]/pricing.md` | Pricing details and comparison |
