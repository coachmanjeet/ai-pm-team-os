# Team Norms

Team agreements for how we work together in this shared repo.

## Repo Contribution Norms

- **Everyone contributes** to their functional area (see onboarding.md for ownership)
- **Use skills** for structured output — don't free-form when a skill exists
- **PR for review** — All substantive changes go through pull requests
- **Keep it current** — Update context files when the product changes
- **No stale context** — If you notice outdated info, fix it or flag it
