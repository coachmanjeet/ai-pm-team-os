# Onboarding — Engineering

Welcome! This guide supplements the [general onboarding](onboarding-general.md) with engineering-specific setup.

## Your Key Folders

| Folder | You Own | What to Do |
|--------|---------|-----------|
| `product-development/engineering/plans/` | Yes | Store implementation plans by product area |
| `product-development/engineering/rfcs/` | Yes | Write technical design proposals |
| `product-development/engineering/bug-investigations/` | Yes | Document bug investigations |
| `product-development/analytics/schemas/` | Co-own | Keep table schemas current |

## Key References

- `context/ARCHITECTURE.md` — System architecture and data model
- `context/TERMINOLOGY.md` — Agentforce terminology (source of truth)
- `product-development/feature-index.yaml` — Find all artifacts for any feature
- `product-development/engineering/bug-investigations/TEMPLATE.md` — Bug investigation format

## Contribution Workflow

1. Write plans/RFCs in the appropriate product area subfolder
2. After investigating a bug, write it up using the template
3. Review PRDs using the engineering-lead perspective
4. Use `/share-update` to notify the team
