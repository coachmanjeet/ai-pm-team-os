# Templates — PM Artifact Formats

Reusable markdown templates for PM artifacts. Skills reference these automatically.

| Template | For |
|----------|-----|
| `prd-template.md` | Product Requirements Documents |
| `spec-template.md` | Engineering specifications |
| `user-story-template.md` | User stories with acceptance criteria |
| `demo-script-template.md` | Demo scripts with narrative flow |
| `weekly-update.md` | Stakeholder weekly updates |
